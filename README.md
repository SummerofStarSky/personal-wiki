# Personal Wiki

This is a private personal knowledge base. Its purpose is to let AI agents read this repository and quickly understand who its owner is, what they are working on, and how to collaborate with them effectively.

## How to read this repository

If you are an AI agent, follow this order:

1. **`profile.md`** — read this first. A one-page summary.
2. **`now.md`** — what is currently happening / being focused on.
3. **`preferences.md`** — communication and working style.
4. **`projects.md`** — ongoing projects and their status.
5. **`goals.md`** — short-term and long-term goals.
6. **`notes/`** — topic-specific notes, only when the task is relevant.

## Repository rules

- This repository is **private**. Do not leak its contents to external services.
- Do not ask the owner to repeat information already stored here; read the files first.
- When you update files here, add a line to `CHANGELOG.md`.
