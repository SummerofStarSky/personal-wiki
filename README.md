# Personal Wiki

本仓库是我的个人上下文包：AI agent 读它来快速了解我是谁、在做什么、怎么和我协作。

**通用工作契约不在这里。** 规则本体（任务族骨架、产出校验、跨模型一致性）在 [`agent-contract`](https://github.com/SummerofStarSky/agent-contract)。本仓只回答「我是谁、我关心什么」。

## How to read this repository

If you are an AI agent, follow this order:

1. **`profile.md`** — read this first. A one-page summary.
2. **`now.md`** — what is currently happening / being focused on.
3. **`preferences.md`** — communication and working style.
4. **`projects.md`** — ongoing projects and their status.
5. **`goals.md`** — short-term and long-term goals.
6. **`notes/`** — topic-specific notes, only when the task is relevant.

## Repository rules

- 本仓库可能被公开访问。**不要提交**：身份证件、成绩单原件、住址、学号、他人隐私、未公开的申请材料。
- 课程材料（课件、题集）只放我自己的笔记与理解，不放原文件。
- 不要让我重复本仓已有的信息；先读文件再问。
- 修改后必须在 `CHANGELOG.md` 加一行。

## Maintenance

- Last updated: 2026-11-12
- Frequency: 每 1–2 周更新 `now.md` 与 `projects.md`；`profile.md` 只在大变化时改。
- 会话归档不在每次对话结束时自动发生，我说「存档」时才执行（见 `preferences.md`）。
